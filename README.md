# AST AI — منصة كل أدوات الذكاء الاصطناعي في مكان واحد

منصة ويب بسيطة (HTML / CSS / JavaScript بدون باك-إند) تجمع ست أدوات ذكاء
اصطناعي في واجهة واحدة، كلها تعمل عبر **Google Gemini API** الرسمي.

## الأدوات

- 💬 **محادثة ذكية** — مساعد محادثة يحتفظ بسياق الحوار.
- 🎨 **توليد الصور** — تحويل وصف نصّي إلى صورة.
- 🎬 **تحريك الصور** — تحويل صورة ثابتة إلى فيديو متحرك (حتى 15 ثانية، عبر Veo).
- 📝 **تلخيص المستندات** — تلخيص النصوص الطويلة بأساليب مختلفة.
- 🌐 **الترجمة الفورية** — ترجمة دقيقة بين عدة لغات.
- ✨ **مولّد البرومت** — تكتب فكرتك بالعربي العادي فيُخرج لك برومت احترافي جاهز.

## التشغيل

1. افتح `index.html` في المتصفح (أو شغّل خادمًا محليًا: `python3 -m http.server`).
2. من صفحة الهبوط اضغط "ابدأ الآن" للدخول إلى `app.html`.
3. اضغط زر الإعدادات ⚙️ وألصق مفتاح Gemini API.
   - احصل على مفتاح مجاني من <https://aistudio.google.com/apikey>.
4. استخدم الأدوات الست.

## الملفات

```
index.html            صفحة الهبوط
app.html              مساحة العمل (الأدوات الست)
assets/css/style.css  التنسيقات
assets/js/app.js      منطق الأدوات والاتصال بالـ API
```

## ملاحظات مهمة

- **المفتاح يُخزَّن في متصفح المستخدم فقط** (localStorage)؛ هذا مناسب للاستخدام
  الشخصي والتجريب. لنشر المنصة كمنتج عام يجب إضافة خادم (Back-end) يحفظ المفتاح
  ويدير التسجيل والاشتراكات والدفع، حتى لا يُكشف المفتاح للمستخدمين.
- **توليد الفيديو (Veo) ميزة مدفوعة** وتتطلب حساب Google Cloud بفوترة مفعّلة.
  أسماء النماذج (المحادثة/الصور/الفيديو) قابلة للتعديل من الإعدادات إذا تغيّرت.
